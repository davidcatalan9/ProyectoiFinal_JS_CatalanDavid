# PC Cotizador - Proyecto Final JavaScript

Este es un cotizador de componentes de PC interactivo construido con HTML, CSS (Bootstrap 5) y JavaScript.

## 🚀 Cómo ejecutar la aplicación

### Opción 1: Abrir directamente (Recomendado)
Simplemente haz doble clic en el archivo `index.html` o arrástralo a tu navegador web favorito.
La aplicación está diseñada para funcionar sin necesidad de un servidor, utilizando datos locales si no se pueden cargar los archivos JSON.

### Opción 2: VS Code Live Server
Si utilizas Visual Studio Code:
1. Instala la extensión "Live Server".
2. Haz clic derecho en `index.html`.
3. Selecciona "Open with Live Server".

## 🛠️ Tecnologías
- HTML5
- CSS3 + Bootstrap 5
- JavaScript (ES6+)
- SweetAlert2 (Alertas)
- Storage API (Persistencia de datos)
